# Agreement

Export → Agreement compares extracted values with a second coder.

1. Download the Coding sheet.
2. The second coder fills `coded_value`, or leaves it blank for not found.
3. Upload it to see agreement per field.

| Measure | Fields |
|---|---|
| Agreement % | all |
| Cohen's kappa | categorical |
| ICC(2,1) (Shrout & Fleiss, 1979) | numeric |
| Mean absolute error | numeric |
| Hallucinations and omissions (Jansen et al., 2026) | all |
