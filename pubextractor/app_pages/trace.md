# Trace and Provenance

Review → Trace shows where a value came from: its page or cell, the rule or model, its checks, and any coder step.

Each coder action (an edit, a confirmation, a role, a calibration) is logged with the coder's initials, typed in Coder in the Model step.

Export gives the trace as JSON and a PRISMA 2020 methods paragraph to edit.
