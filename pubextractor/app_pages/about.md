# About

pubextractor extracts coded values and effect sizes from group, single-case, and correlation design studies. Each value keeps the page or table cell it came from.

## Five steps

1. Papers: add PDF, DOCX, or image files.
2. Codebook: set the fields to extract.
3. Model: rules only, a local model, or an API.
4. Review: confirm or change each recommendation.
5. Export: download the data.

Papers stay on this machine; an API receives text only when the license check allows it.
