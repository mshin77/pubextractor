# Papers and Copyright

| Paper | Web demo | Local app |
|---|---|---|
| Open access (CC BY or similar) | yes | yes |
| Own paper or preprint | yes | yes |
| Subscription paper | no; run locally | yes |
| Terms forbid AI tools | no | rules only |

On the web demo, the License check decides each time whether Gemini may read a paper. When unsure, use the local app: papers never leave the computer.
