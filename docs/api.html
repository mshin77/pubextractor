API Reference#

Reading documents#

Name

Signature

Purpose

read_pdf

read_pdf(path, max_pages=None)

Read a born-digital PDF into per-page text.

detect_page_labels

detect_page_labels(pages)

Attach the page number printed in the document to each page.

detect_sections

detect_sections(pages)

Label each page with section headings and where they sit in its text.

read_docx

read_docx(path)

Blocks of a DOCX file in body order, each with its section and number.

read_docx_images

read_docx_images(path)

Images embedded in a DOCX file, numbered in the order they appear.

read_pdf_tables

read_pdf_tables(path, max_pages=None)

Tables in a PDF, numbered across the document, with file and printed page.

read_tables

read_tables(path, max_pages=None)

Cell grids for every table in a PDF, DOCX, or image file, with caption and note.

read_document

read_document(path, max_pages=None)

Pages and table grids from one pass over a PDF, DOCX, or image file.

table_grid

table_grid(table)

One cell grid for a read_pdf_tables table or a read_docx table block.

table_pages

table_pages(grids)

Tables as page-like blocks, so extract_values and extract_with_rag search them.

read_header

read_header(grid, header_rows=None)

Header rows above the numeric body, joined into one label per column.

parse_cell

parse_cell(text)

Parse a table cell into a kind (number, percent, mean_sd, n_percent, missing, empty, text) and its values.

header_n

header_n(text)

Split a header label from the sample size it states, such as Treatment (n = 24).

Purpose

write_csv

Write rows to a UTF-8 CSV with a header from every key seen.

METAFOR_COLUMNS

METAFOR_COLUMNS

effect_rows(effects)

One flat row per effect, columns in EFFECT_COLUMNS order, for write_csv.

to_metafor

to_metafor(effects)

Rows with yi and vi for metafor, one per effect with a variance.

hedges_j

hedges_j(df)

pooled_sd

pooled_sd(sd_t, sd_c, n_t, n_c)

sd_from_mse

sd_from_mse(mse, r2)

Unadjusted posttest SD from the ANCOVA error mean square; r2 is rho^2 for one pretest.
