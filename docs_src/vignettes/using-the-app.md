# Using the App

Open the [web app](https://www.pubextractor.org), or follow [Getting Started](../getting-started.md) to run it locally.

1. **Papers**: load the examples or add PDF, DOCX, or image files.
2. **Codebook**: import a sheet or edit the fields.
3. **Model**: use rules only, or select a model and check permissions.
4. **Review**: confirm extracted values against the source.
5. **Export**: download the results.

Open **Home** for help. On mobile and tablet, select a **Help topic**.
