# pubextractor

Extract data from papers, review the source evidence, and export results.

## Open the App

Try the [web app](https://www.pubextractor.org) with short papers, or run it locally:

```bash
pip install pubextractor
```

```python
from pubextractor import run_app

run_app()
```

See [Using the App](vignettes/using-the-app.md) for the steps.
